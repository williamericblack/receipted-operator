Audit Trail

receipts, a ledger that refuses unreceipted done, an independent verifier and its oracle

The problem

Agents report "completed" because the code exists, the command ran, or they believe it worked. A status column that anyone can set to green records belief, not fact. Worse, the check that is supposed to catch this can itself silently pass everything, and nothing tells you.

What it is

Receipts for AI and human work: a ledger that refuses "done" without evidence, a verifier that checks independently, and an oracle that catches a broken verifier.

Delivered as a download: method documents, templates and standard-library Python scripts with tests that fail when the method's own logic is broken. Synthetic example data only.
