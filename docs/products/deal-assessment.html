Deal Assessment

deal memo pipeline with red flags, scenarios, kill list and a decomposable confidence

The problem

Deal memos are written backwards: the conclusion first, then the numbers that support it. The awkward fact sits in an appendix, unknowns are treated as "probably fine", the downside case is a gentle haircut on the base case, and the confidence in the conclusion is a feeling.

What it is

A structured deal-memo pipeline: intake that refuses to assume, a red-flag checklist, a scenario table, a kill list, and a verdict with a confidence you can decompose.

Delivered as a download: method documents, templates and standard-library Python scripts with tests that fail when the method's own logic is broken. Synthetic example data only.
